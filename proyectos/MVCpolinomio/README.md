# MVCpolinomio

Un programa que sigue el modelo MVC para recibir un polinomio(sin exponentes 
negativos) del usuario, representarlo en la clase polinomio y mostrarlo en 
la GUI.

# Indice

```
|   ├──models/

|   ├──views/
|   |   └──view.py
|   └──main.py
└──README.md
```

# Virtual Enviroment

## Crear

En el directorio del proyecto:
``bash
python -m venv .venv
``

## Activar

En el directorio del proyecto:
``bash
source .venv/bin/activate
``

## Desactivar

``bash
deactivate
``

# Dependencias
- python 3.14.7+ (garantizado)
